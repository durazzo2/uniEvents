# UniEvents

UniEvents is a university event management web application that allows students and staff to discover, register for, and manage campus events. Students can browse a catalog of events, register with their university email, and receive QR-code tickets for entry. Organizers can create and manage events through a dedicated dashboard, while administrators oversee the platform and moderate listings. The system also sends automated email reminders and in-app notifications to keep participants informed.

## Main Functional Areas

- User Authentication
- Event Catalog
- Registration & Ticketing
- Organizer Dashboard
- Notifications
- Admin Panel
